# Interface Cinemática

Plugin (formato Claude) que vem com o FilmForge. Ative-o em **Novo projeto → Plugins** para que
as cenas por código e os motion graphics sejam feitos com acabamento de interface premium:
grid e área segura para 16:9 e 9:16, escala tipográfica, tokens de cor, movimento determinístico
sincronizado à narração e componentes pensados para vídeo (cartões de dado, gráficos, listas,
interfaces simuladas).

Quando o plugin está ativo, o FilmForge coloca a LLM indicada — **Claude Opus** pelo harness
`claude` (reserva: Gemini pelo Antigravity) — à frente da cadeia das etapas "Cena por código" e
"Motion graphics". Os executores da rota continuam como reserva, e uma escolha feita por você em
"Provedores → por etapa" sempre vence a recomendação.
